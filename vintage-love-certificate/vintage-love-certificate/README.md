# Vintage Love Certificate Website

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is needed for Google Fonts and the YouTube embed.

## Files
- `index.html` – page structure and content
- `style.css` – vintage styling, responsive layout, animations, dark mode
- `script.js` – name/title flow, fireworks, petals, music controls, note modal, PNG export

## Notes
- Music playback is controlled through the embedded YouTube player. Browsers may require the visitor to press Play.
- The certificate download is generated locally as a high-resolution PNG.
- The theme preference is saved in localStorage.
